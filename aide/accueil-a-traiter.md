La page Accueil s'ouvre après la connexion. Elle réunit ce qui demande votre attention et votre journée. Chaque bloc ne s'affiche que si vous avez de quoi le remplir.

## Les blocs de la page

- **À traiter** liste les actions qui vous attendent, selon vos droits. Chaque ligne mène à la page qui la règle. Le bloc disparaît s'il n'y a rien à faire.
- **Aujourd'hui** montre vos rendez-vous du jour. Sans rendez-vous, les prochains des **7 prochains jours** s'affichent. Cliquez sur **Ouvrir l'agenda** pour voir le détail.
- **En service** montre qui est en service en ce moment. Au-delà de huit personnes, cliquez sur « Voir les N autres » (N est le nombre de personnes restantes) pour déplier la liste, puis sur **Réduire la liste** pour la replier.
- **Cette semaine** donne vos chiffres, avec une barre de progression vers l'objectif. Cliquez sur une ligne pour ouvrir la page qui la détaille.

::: info
Si une partie de la page ne se charge pas, un message vous le dit. Rechargez la page dans un instant.
:::

## Ajouter un rendez-vous depuis l'accueil

::: etapes
**Repérez le bloc Aujourd'hui.** Sans rien de prévu, il affiche « Rien de prévu aujourd'hui. »
**Cliquez sur** [Ajouter un rendez-vous]. L'agenda s'ouvre sur un nouvel événement.
:::

::: si rh-voir
Avec le droit de consulter l'équipe, le bloc **Cette semaine** ajoute le run et la facturation de l'équipe, avec l'écart par rapport à la semaine précédente. Le lien **Voir le quota** ouvre la page Quota.
:::
