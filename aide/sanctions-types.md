Les types classent les sanctions par gravité et les font repérer par couleur. Il en faut au moins un pour pouvoir sanctionner.

## Créer un type

::: etapes
**Ouvrez la fenêtre.** Cliquez sur **Gérer les types**, ou sur **Créer des types** s'il n'y en a pas encore.
**Nommez le type.** Écrivez un nom court dans le champ Nom, par exemple « Avertissement oral ».
**Choisissez une couleur.** Elle sert à repérer le type dans la liste.
**Cliquez sur** [Ajouter] pour créer le type.
:::

## Modifier ou supprimer un type

Dans la liste **Types existants**, cliquez sur [Modifier] pour changer le nom ou la couleur, puis sur [Enregistrer]. [Annuler] referme la modification sans rien changer.

Le bouton **Supprimer** demande une confirmation. Les sanctions qui utilisaient ce type restent dans l'historique, avec la mention « Sans type ».

::: info
Fermez la fenêtre avec la croix ou la touche {Échap}.
:::
