La page Mon compte s'ouvre en cliquant sur votre nom en bas du menu. En tête, vous voyez votre nom, votre grade et, si une fiche employé vous est reliée, votre ID Unique et votre date d'arrivée. Ces informations ne se modifient pas ici : un supérieur les tient.

## Changer vos informations

::: etapes
**Ouvrez Mon compte.** Cliquez sur votre nom en bas du menu.
**Modifiez le nom.** Dans **Mes coordonnées**, corrigez le champ **Prénom et nom en jeu**.
**Complétez la fiche.** Renseignez **Téléphone** et **RIB**. Ces deux champs n'existent que si une fiche employé est reliée à votre compte.
**Cliquez sur** [Enregistrer]. Le message « Coordonnées enregistrées. » confirme l'opération.
:::

Le RIB est masqué. Cliquez sur l'icône en forme d'œil pour l'afficher, puis de nouveau pour le masquer.

Pour revenir aux valeurs enregistrées, cliquez sur [Annuler] avant d'enregistrer.

::: info
Sans fiche employé, la page vous le dit : un supérieur doit d'abord vous en créer une. Seul le nom en jeu reste modifiable.
:::
