Quand le recrutement passe par le bot Discord, une candidature acceptée dans Discord crée seule la fiche de la personne. Les candidatures arrivent dans l'onglet **Candidatures**, section **Recrutement**.

## Lire l'état d'une candidature

- **Fiche créée** : la fiche existe. Ouvrez-la avec le bouton **Ouvrir la fiche** suivi de son ID Unique.
- **Avait déjà une fiche** : la personne était déjà dans l'effectif.
- **À traiter** : les réponses n'ont pas pu être lues. Le motif est écrit sur la carte.
- **Écartée** : aucune fiche n'a été créée.

Les candidatures « À traiter » passent en tête de la liste. Elles apparaissent aussi dans le bloc **À traiter** de l'onglet Effectif.

## Traiter une candidature en attente

::: etapes
**Lisez le motif.** Il dit ce qui manque, par exemple le prénom ou le nom.
**Corrigez les réglages si besoin.** Dans l'onglet **Réglages du recrutement**, ajustez la fiche créée à l'acceptation, puis cliquez sur [Enregistrer].
**Cliquez sur** [Retraiter] pour recréer la fiche avec les nouveaux réglages.
:::

Pour ne pas créer de fiche, cliquez sur [Écarter] puis confirmez : ses réponses sont effacées. [Retraiter] et [Écarter] demandent le droit d'ajouter un employé.

::: si rh-parametrer
Dans les réglages, choisissez le Grade donné à toutes les arrivées. Indiquez aussi, pour le prénom, le nom, l'ID Unique, le téléphone et le RIB, la question du formulaire dont vient la réponse. Le prénom et le nom sont obligatoires.
:::

::: info
Si aucune candidature n'arrive, demandez à la personne qui s'occupe du site de vérifier l'abonnement « Candidatures » du bot.
:::
