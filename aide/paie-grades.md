Dans {chemin:Comptabilité›Paie}, l'onglet **Grades** liste les grades avec leur salaire de base et leurs primes résumés. Vous ne gérez que les grades sous le vôtre.

## Modifier un grade

::: etapes
**Ouvrez la fiche** Cliquez sur le grade dans la liste.
**Réglez le salaire de base** Activez l'interrupteur, puis saisissez le montant par semaine. Il est versé chaque semaine à qui a ce grade, en plus des primes.
**Ajoutez des paliers de prime** Dans « Primes — Run » (unités vendues par semaine) ou « Primes — Factures » (dollars facturés par semaine), cliquez sur [Palier]. Saisissez le seuil et la prime.
**Retirez un palier si besoin** Cliquez sur la corbeille de sa ligne.
**Enregistrez** Cliquez sur [Enregistrer].
:::

## Comment les primes se calculent

Dans chaque échelle, seul le palier le plus haut atteint compte : les paliers ne se cumulent jamais. En revanche, la prime run et la prime facture s'additionnent entre elles. Sous chaque échelle, un aperçu vous aide à contrôler les paliers saisis.

::: info
Le salaire de base est le même que celui utilisé par la paie à l'heure de la page DOT. Les montants réglés ici valent à partir de maintenant : ils ne réécrivent pas une semaine déjà verrouillée.
:::
