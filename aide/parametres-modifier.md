La page Paramètres regroupe les liens et réglages du site. Ils sont rangés par onglet, et chaque réglage s'applique dès l'enregistrement.

## Modifier un onglet

::: etapes
**Choisissez l'onglet.** Les onglets dépendent de votre site, par exemple **Discord**, **Quota** et **Contrats**.
**Changez les valeurs.** Le texte « Modifications non enregistrées » apparaît en bas de page dès que vous touchez à un champ.
**Cliquez sur** [Enregistrer]. Seul l'onglet affiché est enregistré.
:::

Si vous changez d'onglet avec des modifications en cours, le site vous demande de confirmer : choisissez **Abandonner les modifications** pour les perdre, ou annulez pour rester.

## Choisir un rôle, un salon ou une catégorie Discord

Quand le bot Discord est relié au site, ces réglages se choisissent par leur nom dans une liste. Cliquez sur **Choisir…** ou **Ajouter…** pour en prendre un, et sur la croix d'une étiquette pour la retirer.

Sans bot relié, le champ attend l'identifiant Discord. Dans Discord, activez le mode développeur (Paramètres, Avancés), faites un clic droit sur le rôle, le salon ou la catégorie, puis choisissez « Copier l'identifiant ».

## Les autres types de réglages

- **Liens** : une adresse complète (https://…). Un lien laissé vide masque son bouton sur le site public.
- **Objectifs de l'onglet Quota** : le total que toute l'équipe vise chaque semaine, pour le run et pour les factures. Avec 0, aucun objectif n’est affiché.
- **Jours autorisés de l'onglet Contrats** : cliquez sur les jours (Lun à Dim) où un client peut modifier la liste de ses bénéficiaires. Aucun jour coché : il ne peut jamais la modifier.

::: info
Dans l'onglet **Discord**, un message en haut de page indique si le bot est relié et si des prises de service ont été reçues.
:::
