La page Sanctions réunit l'historique disciplinaire de tous les employés. L'employé sanctionné voit la sanction, son type et la note dans **Mon compte**.

## Consulter les sanctions

La liste donne l'employé (avec le rang de la sanction : 1re, 2e…), le type, la date, la note et l'auteur. Tapez un nom ou un prénom dans la recherche, ou cliquez sur un type dans **Filtrer par type** pour n'afficher que celui-là. Un second clic revient à tous les types.

## Ajouter une sanction

Cette action demande le droit de gérer les sanctions.

::: etapes
**Cliquez sur** [Ajouter une sanction] en haut de la page.
**Choisissez l'employé.** La liste ne propose que les employés actifs.
**Choisissez le type.** S'il n'y en a aucun, créez-en un d'abord avec **Créer des types**.
**Écrivez une note.** Elle est facultative : ce qui s'est passé, en une ou deux phrases.
**Cliquez sur** [Ajouter] pour inscrire la sanction.
:::

## Retirer une sanction

::: si rh-sanctionner
Ouvrez le menu des actions de la ligne, choisissez **Retirer la sanction**, puis confirmez. Elle est supprimée définitivement de l'historique.
:::

::: attention Les sanctions sont visibles de l'employé
Écrivez une note factuelle : l'employé la lit dans son compte.
:::
